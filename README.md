# COP-4331-LAMP-Stack
Version Control tracking

## Description of the COLORS application: 
The application takes in users and allows them to log in. After logging in, users are able to save new colors and look through them. All data is stored for the user when they come back. 

## Technologies used: 
* LAMP-STACK, LINUX
* HTML, CSS, JAVASCRIPT
* PHP, APACHE
* MYSQL

## High-level setup instructions
1. Create the server.
2. Connect a domain. 
3. Check the web server. 
4. Set up the database. 
5. Create the folder structure. 
6. Configure and upload the API. 
7. Test the API. 
8. Upload and configure the front end. 
9. Test the full app. 

## How to run and access the applicaiton
1. Go to http://isasn.com.
2. Log in with a user from the Users table
3. Once you're logged in, the app takes you to color.html, where you can search for and add colors.
